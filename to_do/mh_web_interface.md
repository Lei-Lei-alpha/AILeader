# Metal hydride web interface

## Database
Search, query, and add of metal hydrides

## Calculation
Van't Hoff equation for the equilibrium pressure of hydrogen absorption/desorption

## Prediction
Predict the properties of metal hydrides based on the composition and structure using stored models

## Visualization
Visualize the properties of metal hydrides

## User management
User authentication and authorization

## Orcherstration
Allow use of chat to query and submit simulation jobs
