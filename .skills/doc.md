# Document Generation Skill (Local)

Use this skill to create a professional Word (.docx) document.

## Instructions
1. Plan the document title and major sections.
2. For each section, provide a "heading" and "content".
3. Trigger the skill using the following tag:
<CALL_SKILL name="doc">{"title": "Document Title", "sections": [{"heading": "Section Heading", "content": "Detailed text..."}]}</CALL_SKILL>
